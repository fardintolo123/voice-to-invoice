# Session / Chat Naming

At the start of every Codex or GitHub Copilot session, include the repository's project prefix in the chat or session title so this voice-to-quote and invoice project is immediately identifiable.

Use the prefix **`4ElementsPainting-1`** followed by a short task description. For example:

- **`4ElementsPainting-1 - Improve voice quote extraction`**
- **`4ElementsPainting-1 - Fix invoice PDF totals`**
- **`4ElementsPainting-1 - Update customer quote form`**

Preserve the `4ElementsPainting-1` prefix when renaming or continuing the session. If the tool cannot rename the title automatically, state the suggested title in the first response and use the same format for the session label whenever the interface allows it.
